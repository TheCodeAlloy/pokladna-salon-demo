# Pokladna salonu – veřejná DEMO verze

Tento repozitář obsahuje **pouze veřejný testovací prototyp** mobilní pokladny pro salon svatebních šatů a oprav oděvů.

- Žádná skutečná komunikace s EET
- Žádná serverová databáze, přihlášení ani automatické e-maily
- Testovací prodeje, výdaje a zákazníci se ukládají **jen lokálně v konkrétním prohlížeči (IndexedDB)**
- Při smazání dat prohlížeče se údaje mohou ztratit
- Bezpečné pouze pro **fiktivní testovací údaje**, nikdy ne pro reálné podnikání

Hlavní vývoj probíhá v soukromém repozitáři.
